# Chaerin Rule Word Chain Bot (채린룰 끝말잇기 봇)

메신저봇 R (카카오톡 봇) 환경에서 구동되는 **채린룰** 특화 25개 직업 끝말잇기 게임 엔진입니다.

## 📂 폴더 구조

- **Optimized_Code/**: 배포용 최적화 및 난독화 코드
- **Data_Files/**: 게임 구동에 필요한 JSON 데이터 (diesyl.json 등)

## 🚀 시작하기

1. `Data_Files/diesyl.json` 파일을 스마트폰의 `/sdcard/msgbotr/` 폴더에 복사합니다.
2. `Optimized_Code/bot_v2_obfuscated.js` 의 전체 내용을 복사하여 메신저봇 R의 스크립트로 등록합니다.
3. `%도움말` 명령어를 통해 게임 방법을 확인하세요.
